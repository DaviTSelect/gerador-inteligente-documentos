# Gerador Inteligente de Documentos v1.2.0

- O documento gerado mantém a formatação original do modelo (negrito, fonte, cor etc.).
- Atualização automática mais segura: o arquivo é conferido antes de substituir o programa.
- Em caso de falha na atualização, a versão atual é mantida e há a opção de tentar novamente.

## Instalação

Baixe `GeradorDocumentos.exe` e execute. Quem usa a versão 1.1.x precisa baixar este arquivo manualmente uma única vez; a partir da 1.2.0 as atualizações são automáticas.
