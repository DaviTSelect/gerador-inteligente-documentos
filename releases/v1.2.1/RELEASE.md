# v1.2.1

## Corrigido

- Verificação de atualização que falhava em alguns computadores: o certificado do GitHub agora é validado pelo próprio Windows.
- As mensagens de falha na atualização informam o motivo.
- O mapeamento automático liga `{{Valor_PSU}}` à coluna `PSU_VALOR` (mesmas palavras em outra ordem).
- A conversão para PDF tenta novamente quando o Word recusa uma chamada.

## Requisitos

Windows 10 ou 11, 64 bits. O Microsoft Word é necessário apenas para gerar PDF.

## Como atualizar

- **Quem usa a 1.2.0:** o programa oferece a atualização. Se a 1.2.0 não conseguir verificar neste computador, baixe a 1.2.1 manualmente.
- **Quem usa a 1.1.x:** baixe `GeradorDocumentos.exe` desta página e substitua o antigo.
